# Laundry Service Website

A **responsive and user-friendly website** for a laundry service business, designed to showcase services, provide contact information, and allow customers to learn about the business online.

---
website: https://cleanpointcleaningsolutions.co.ke/ 

## 🎯 Purpose
This website serves as an **online presence for a laundry business**, helping customers:

- Explore available laundry services
- Learn about the business and team
- Contact the business for inquiries or bookings

It’s designed to be simple, intuitive, and visually appealing.

---

## 🛠 Features
- Homepage with an overview of services
- About page detailing the business and mission
- Services page listing laundry offerings
- Contact page with a form or contact details
- Fully **responsive design** for desktop, tablet, and mobile

---

## ⚡ Technology Stack
- **Frontend:** HTML5, CSS3, JavaScript
- **Styling:**  Bootstrap 
- **Images & Icons:** Static assets included in the project
- No backend required
